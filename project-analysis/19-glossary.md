# مسرد المصطلحات الفنية والأكاديمية (Project Glossary)
## Attendance Recording System — عربي / إنجليزي

---

### 1. المصطلحات الهندسية والتقنية (Technical Architecture Terms)

| المصطلح بالإنجليزية (English) | المصطلح بالعربية | الشرح والتعريف الفني في سياق النظام |
|---|---|---|
| **Monorepo** | مستودع أحادي متعدد الحزم | بنية معمارية لإدارة عدة مشاريع وتطبيقات مستقلة (`apps/api` و `apps/web`) داخل مستودع كود واحد وتنسيق تبعياتها عبر `pnpm workspaces`. |
| **RBAC (Role-Based Access Control)** | التحكم بالوصول القائم على الأدوار | نمط أمني لإدارة صلاحيات المستخدمين بحصر العمليات المسموحة في مصفوفة محددة وفق الدور الوظيفي للموظف (`StaffRole`). |
| **Deny-by-default** | الأمان بالرفض الافتراضي | استراتيجية أمنية تقضي بحظر كافة مسارات النظام افتراضياً ما لم يتم وسمها بصراحة بأنها عامة (`@Public()`) أو يمتلك المستخدم الصلاحية اللازمة. |
| **PostgreSQL Advisory Lock** | القفل الاستشاري في PostgreSQL | آلية قفل برمجية ذرية (`pg_advisory_xact_lock`) على مستوى المعاملات تُحجز لكل محاضرة لمنع تسابق عمليات المسح والتسجيل والإغلاق المتزامنة. |
| **Atomic Close** | الإغلاق الذري للمحاضرة | تنفيذ تغيير حالة المحاضرة إلى مغلقة واحتساب غيابات كافة الطلاب غير المسجلين داخل معاملة قاعدة بيانات واحدة تنجح كلياً أو تفشل كلياً دون ترك حالات معلقة. |
| **Timing Attack** | هجوم التوقيت التخميني | أسلوب لاختراق الحسابات بقياس الفارق الزمني لاستجابة الخادم بين المستخدمين الموجودين وغير الموجودين؛ تم تحصين النظام منه بحساب تجزئة وهمية ثابتة (`DUMMY_HASH`). |
| **Rate Limiting** | الحد من معدل الطلبات والتخمين | تقنية أمنية لتقييد عدد محاولات تسجيل الدخول الفاشلة المتتالية لكل حساب ولكل عنوان IP لحماية النظام من هجمات القوة الغاشمة (Brute Force). |
| **HttpOnly Cookie** | كوكي محجوب عن الجافاسكربت | سمة أمان للكوكيز تمنع سكربتات المتصفح من قراءة رمز الجلسة، مما يحمي المستخدم تماماً من سرقة حسابه عبر ثغرات حقن السكربتات (XSS). |
| **Opaque Token** | رمز عشوائي مبهم | رمز مشفر عشوائي لا يحمل أي بيانات مدمجة عن الطالب بداخله، ويستخدم فقط كمرجع للبحث في جدول الرموز المصدرة `StudentQrToken`. |
| **Token Rotation** | تدوير الرموز الدوري | آلية أمنية تغير رمز الـ QR المعروض في قاعة المحاضرات كل 22 ثانية مع إبطال الرمز السابق بعد 25 ثانية لمنع تصوير الشاشة وتمرير الرمز خارج القاعة. |
| **Soft-Delete** | الحذف المنطقي / الأرشفة | تعليم السجل في قاعدة البيانات بحقل زمني `deletedAt != null` بدلاً من حذفه فيزيائياً، للحفاظ على السجلات التاريخية للتدقيق والإحصائيات. |
| **IDOR (Insecure Direct Object References)** | المراجع المباشرة غير الآمنة للكائنات | ثغرة تسمح بتغيير معرف الكائن في الرابط للوصول لبيانات محظورة؛ تم تحصين النظام منها برفض أي طالب لا ينتمي للمواد المسندة للتدريسي. |
| **WebSocket / Socket.IO** | قناة الاتصال الحي ثنائي الاتجاه | بروتوكول اتصال شبكي فوري يبث تحديثات مسح بطاقات الطلاب وتدوير رمز الـ QR لحظياً بين خادم الـ API وشاشة قاعة المحاضرات. |
| **Database Drift** | تباين وفجوة ترحيل البيانات | حالة عدم تطابق بين ملفات الترحيل المكتوبة في الكود وتلك المطبقة فعلياً على قاعدة بيانات الإنتاج. |

### 2. المصطلحات الأكاديمية والوظيفية (Academic & Domain Terms)

| المصطلح بالإنجليزية (English) | المصطلح بالعربية | المعنى والتطبيق العملي في النظام |
|---|---|---|
| **Academic Stage** | المرحلة الأكاديمية | السنة الدراسية للطلبة في الكلية (المرحلة 1، 2، 3، 4). النظام يركز حالياً على المرحلة الثانية مع جاهزية الهيكل لكافة المراحل. |
| **Study Period** | نوع الدراسة / الفترة | تصنيف الدراسة إما صباحية (`MORNING`) أو مسائية (`EVENING`). |
| **Section** | الشعبة الدراسية | التقسيم الفرعي لطلبة المرحلة (مثال: شعبة 1، شعبة 2)، وتكون تابعة لمرحلة وفترة دراسية محددة. |
| **Course** | المقرر / المادة الأكاديمية | المادة الدراسية المقررة لمرحلة معينة (مثل مادة "الفطريات" أو "علم الدم") ولها رمز فريد (`code`). |
| **Teaching Assignment** | التعيين التدريسي | قيد في جدول `TeachingAssignment` يربط عضو الكادر (أستاذ أو فني) بمادة أكاديمية محددة لمنحه صلاحية إدارتها. |
| **Multi-Section Lecture** | محاضرة متعددة الشعب | محاضرة واحدة تُعقد وتُسجل لأكثر من شعبة معاً في نفس الوقت داخل قاعة أو مدرج مشترك (ترتبط عبر جدول `LectureSection`). |
| **Timetable Entry** | الموعد الأسبوعي في الجدول | قيد في جدول المواعيد الأسبوعية يحدد يوم وتوقيت انعقاد المحاضرة لكل مادة وشعبة؛ وهو المنظم لأحقية الحضور التبادلي. |
| **Cross-Section Attendance** | الحضور التبادلي بين الشعب | حضور الطالب جلسة لمادته مع شعبة موازية لشعبته، وتُسجل كـ "حاضر بملاحظة" ولا يُحسب غائباً في محاضرة شعبته الأصلية في ذلك الأسبوع. |
| **ISO Calendar Week** | الأسبوع التقويمي ISO | النافذة الزمنية الأسبوعية الصارمة (من الأحد للسبت أو الاثنين للأحد) المعتمدة لاحتساب قاعدة التغطية ومنع الغياب الجائر للطلاب. |
| **Absence Threshold** | حد الإنذار الأكاديمي | عدد ساعات أو محاضرات الغياب التي إذا بلغها الطالب دخل في دائرة الخطر ويُصدر بحقه إنذار رسمي. |
| **Debarment / Deprivation** | الحرمان الأكاديمي | إسقاط حق الطالب في أداء الامتحان النهائي للمادة بسبب تجاوزه الحد الأقصى المسموح به للغياب (عادة 10% فأكثر). |
| **Reset Absences** | تصفير سجلات الغياب | إجراء إداري استثنائي لحذف سجلات الغياب لمرحلة وشعبة محددة بقرار رسمي، مع إبقاء المحاضرات المغلقة كما هي وتوثيق العملية في التدقيق. |

### 3. أدوار ومسميات الكادر الوظيفي (Staff Roles)

| الرمز البرمجي (Role Key) | المسمى الوظيفي بالعربية | نطاق المسؤولية والصلاحية |
|---|---|---|
| `SYSTEM_OWNER` | **مالك النظام (تجريبي)** | الحساب التقني الأولي لتثبيت النظام؛ فائق الصلاحيات ولا يمكن تعديله أو حذفه عبر الواجهة. |
| `HEAD_OF_DEPARTMENT` | **رئيس القسم** | المسؤول الأكاديمي والإداري الأعلى؛ يمتلك صلاحيات شاملة للمحاضرات، الطلاب، الكادر، والتقارير وسجل التدقيق. |
| `REGISTRAR` | **المسجل / شؤون الطلبة** | مسؤول القيود والجداول والشعب والطلاب وتصفير الغيابات وإسناد المواد للمدرسين. |
| `LECTURER` | **أستاذ المادة / المحاضر** | التدريسي المسؤول عن إلقاء المحاضرة وفتح الجلسة ومسح البطاقات واستعراض تقارير مواده فقط. |
| `TECHNICAL_LECTURER` | **المحاضر التقني / الفني** | فني المختبر؛ مسؤول عن فتح الجلسة ومسح البطاقات بالكاميرا دون صلاحية التسجيل اليدوي أو التقارير. |
